# TactCs

A tactical team shooter made in Unity, with an original map and online multiplayer.

## How to play (Windows)

1. Click **CS.zip** above, then the **Download** button (the download arrow).
2. Unzip it and run the `.exe` inside the folder. Keep all the files together.
3. If Windows shows "Windows protected your PC", click **More info → Run anyway**.
4. Allow the game through the firewall if asked.
5. One player picks **Host Online** and shares the join code. Everyone else picks **Join Online** and enters it.
